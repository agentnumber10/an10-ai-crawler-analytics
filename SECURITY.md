# Security

Please report a vulnerability privately, never in a public issue:

- through GitHub: **Security → Report a vulnerability** on this repository, or
- by email to rakesh@agentnumber10.com.

Include the plugin version, what an attacker can do, and the steps to
reproduce it. You will get a reply within three working days, and a fix is
released as soon as it is ready. Reporters are credited in the changelog unless
they prefer not to be.

Only the latest release is supported.
